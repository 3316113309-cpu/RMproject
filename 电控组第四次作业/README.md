- TIM2 挂在 APB1 上。工程中系统时钟为 72MHz，APB1 二分频得到 36MHz；因为 APB1 分频系数不为 1，定时器时钟自动乘 2，所以 **TIM2 时钟为 72MHz**。

  为方便将脉宽直接写入 CCR，选择计数频率为 1MHz，即每计数一次为 1μs：

   

计数频率 = TIM2时钟 / (PSC + 1)

PSC = 72,000,000 / 1,000,000 - 1
    = 71

- 舵机需要 50Hz PWM，对应周期为 20ms，即 20,000μs：

PWM频率 = 计数频率 / (ARR + 1)

ARR = 1,000,000 / 50 - 1
    = 19999

- 两端取 550μs 和 2450μs，是为了给舵机机械限位留出余量

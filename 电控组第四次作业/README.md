- TIM2 挂在 APB1 上。工程中系统时钟为 72MHz，APB1 二分频得到 36MHz；因为 APB1 分频系数不为 1，定时器时钟自动乘 2，所以 **TIM2 时钟为 72MHz**。

  为方便将脉宽直接写入 CCR，选择计数频率为 1MHz，即每计数一次为 1μs：

   

计数频率 = TIM2时钟 / (PSC + 1)

PSC = 72,000,000 / 1,000,000 - 1
    = 71

- 舵机需要 50Hz PWM，对应周期为 20ms，即 20,000μs：

PWM频率 = 计数频率 / (ARR + 1)

ARR = 1,000,000 / 50 - 1
    = 19999

- 两端取 550μs 和 2450μs，是为了给舵机机械限位留出余量

- 我在原有定角序列的基础上加入两个按键，让手动调节与自动运行共用同一个目标角度变量。PA1 对应加 15°，PA2 对应减 15°，都配置为上拉输入，按下时为低电平。

  具体思路如下：

  1. **用计时替代阻塞延时。**    主循环持续扫描按键，通过 HAL_GetTick 判断是否到达自动偏转的 1 秒间隔，不使用 hal_delay，使等待期间仍能响应按键。

  2. **消抖后执行一次调节。**    检测到按键电平变化后，确认它稳定约 20ms，才认定按下。只在确认按下的瞬间执行一次，因此长按不会连续加减，也不必等松开后才转动。

  3. **先判断范围，再更新角度。**    用带符号临时变量计算“当前目标 ±15°”。结果在 0～180° 内才更新目标并输出 PWM；越界则忽略，原目标保持不变。例如 180° 时按加无效，再按减仍能正常得到 165°，不会受到上一次越界操作影响。

  4. **按键优先，松开后恢复自动序列。**    任一按键按住时暂停自动步进，并重新计时；两键都稳定松开约 1 秒后，继续原固定序列的下一个角度。手动操作只改变当前目标，不修改固定序列。例如自动运行到 90° 时按加，先转到 105°，松开后下一点仍是 135°。

  每次有效角度变化后，都同步更新舵机 PWM、OLED 和串口信息，使控制目标与显示内容保持一致。
